## Icons

All UI icons (about 60) and the social icons are an original inline SVG sprite drawn for this template (24 × 24 grid, 1.8 px stroke) and defined in each page's markup. No icon library is used.

## Illustrations

The SVG booth renders (portfolio), floor plans, patterns and logo in `assets/images/` were generated for this template with a small isometric drawing script and are original works. Service, process, blog and hero visuals are royalty-free photographs — see **Photography** below.

## JavaScript and CSS libraries

None. All behaviour is vanilla JavaScript; all styling is hand-written CSS.

## External assets loaded at runtime

- Google Fonts stylesheet and font files (`fonts.googleapis.com`, `fonts.gstatic.com`).
- Social links and share buttons point to the networks' own sites; nothing from them is embedded.
- The "Open in Maps" link opens Google Maps in a new tab. No map iframe or map script is embedded.

## Demo content

Company names (Standform and every client), people, quotes, addresses, phone numbers, prices and statistics are fictional. The email domain `standform.example` and phone numbers in the `555-01xx` range are reserved for fictional use. Trade show names (for example "TechForward Expo") are invented.

## Data-visualisation approach

The dashboard charts follow a fixed categorical order (blue, orange, aqua, yellow, magenta), thin marks with rounded data ends, a legend for multi-series charts, hover tooltips and a table alternative for each chart.
